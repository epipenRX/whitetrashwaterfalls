# White Trash Waterfalls

Staging site for whitetrashwaterfalls.com — a backyard PVC pipe waterfall arc built over an above ground pool.

## Structure

- `index.html` / `style.css` — the site
- `images/` — drop photos here, then reference them in `index.html`'s gallery section

## Hosting

Served via GitHub Pages from the `main` branch, currently at the default
`https://epipenrx.github.io/whitetrashwaterfalls/` URL. A custom domain
(whitetrashwaterfalls.com) will be wired up later once DNS is pointed at
GitHub Pages — see the repo's Pages settings when that happens.
