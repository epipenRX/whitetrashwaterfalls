# White Trash Waterfalls

Site for whitetrashwaterfalls.com, a custom pool business with an emphasis on above ground pools: plumbing, pump installation and repair, maintenance, and custom water features (the flagship being a custom PVC waterfall arc).

## Structure

- `index.html` / `style.css`, the site
- `images/logo.svg`, the logo (simple vector placeholder, swap for a designer version whenever)
- `images/`, drop photos here, then reference them in `index.html`'s gallery section
